# Responsive screenshot evidence

Capture screenshots from the final site in the browser's responsive/device toolbar and save them here as:

- `evidence-laptop.png` — desktop around 1440 × 900
- `evidence-tablet.png` — tablet 768 × 1024
- `evidence-mobile.png` — mobile 390 × 844

Do not use screenshots from an earlier design or resize one screenshot to imitate another viewport. After capturing, insert the screenshots into the main `README.md` if required by the assessment brief.
